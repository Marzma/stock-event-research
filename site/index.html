01 / The question

What happened around the move?

A large return is easy to spot. Connecting it to a reliable source, with the correct timing and an honest denominator, is harder.

THE STARTING POINT

A single-company study

The initial NBIS project compared daily prices with QQQ, examined five Federal Reserve rate cuts and created a manually reviewed event register. It exposed the friction of repeating the same steps for every ticker.

THE RESULT

A configuration-driven workflow

Provider adapters, SQL calculations, explicit missing-data states and a repeatable reporting layer turn that process into a small research tool. Change the watchlist and run the pipeline again.

02 / How it works

04 / Engineering decisions

Correctness before a convincing story.

The goal is to expose what the data supports, including gaps and uncertainty.

What is tested

  • Exactly 5% stays outside a strictly greater-than-5% filter.
  • Missing benchmark sessions cannot become multi-day daily returns.
  • Adjusted prices handle a stock split without a false return jump.
  • After-close and weekend news matches the next observed session.
  • Missing event endpoints remain unavailable rather than zero.
  • External source text cannot break out of the dashboard data block.

Inspect the CI runs ↗

Checked against the NBIS case

The general pipeline reproduced 118 rally dates and all 20 original event windows using the original private input files. An AAPL/QQQ online price-download smoke test also completed locally.

These are author-reported regression checks. Public fixture tests are reproducible in CI; the original downloaded market files are not redistributed.

Implementation and documentation were developed with AI assistance. The repository exposes the methods, tests and limitations for independent review.

05 / Research boundaries

Association is not causation.

Clear limitations are part of the deliverable.

Deliberate safeguards

No invented news explanations. No silent fallback from adjusted to raw prices. No zero-filled missing windows. API quotas and incomplete coverage stay visible.

The MIT license covers the project code and documentation, not market data or news supplied by third parties.

What still needs work

Independent exchange calendars, early closes, intraday responses, policy surprises and beta-adjusted abnormal returns are not modeled. The macro calendar is a curated input, not a live feed.

Live news API collection and optional MySQL export have not received end-to-end online validation. Provider coverage limits apply.

06 / Reproduce it

Small setup. Real outputs.

Run locally without API keys or a database server, then configure real providers when ready.

python -m pip install -e .
stock-research --config examples/demo.json --output artifacts/demo
python -m unittest discover -s tests -v
What does the pipeline produce?

A self-contained dashboard, an English Markdown report, daily returns, large-move and macro-window CSVs, a machine-readable snapshot and a local SQLite database.

Can I analyze other equities?

Yes, if your provider supports them. Configure the watchlist, benchmark, date range and market timezone. This is not a guarantee of complete global-market coverage or exhaustive historical news.

Is the project open source?

Yes. Code and documentation are MIT licensed. Preserve the copyright and license notice when reusing them. Third-party data has separate terms.
